## 节点说明

| 节点 | 模型 | 说明 |
|:--|:--|:--|
| **Router** | qwen3.7-plus | 识别 5 种意图：CHITCHAT / DATA_QUERY / KB_QA / HANDOFF / CLARIFY |
| **Retrieval** | text-embedding-v4 | 向量化 → Qdrant 语义搜索 → 重排序 |
| **Data Query** | qwen-plus | `_select_api` 选接口 → `_call_api` 调充电桩 API → `_generate_answer` 生成回答 |
| **Generation** | qwen-plus | 根据意图分支组装不同 Prompt，生成最终回答 |
| **Guardrails** | - | 敏感词检测（银行卡号、密码等）、回答长度截断 |
| **Memory** | - | 对话窗口裁剪，保留最近 10 轮（20 条消息） |

## 直通路径

当用户输入匹配到明确的数据查询意图时，`_select_api` 会返回对应的 API 编号。如果匹配成功，则**绕开 LangGraph 工作流**，直接经过 `data_query_direct` → Generation → Guardrails → Memory，节省一次 Router 的 LLM 调用。
